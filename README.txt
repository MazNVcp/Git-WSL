# Git-WSL & Linux Infrastructure Lab

This repository documents hands-on technical labs focused on version control workflows, Linux system administration, and secure remote server management.

## Key Competencies Demonstrated:
- **Version Control (Git & GitHub):** Implemented Git branching strategies (`main`, `hotfix`, `sidebarDesign`), commit tracking, and remote repository management.
- **Linux OS & Network Configuration:** Configured Ubuntu Linux environments, static IP networking via Netplan, and local virtual machines (VirtualBox).
- **Secure Server Access:** Set up and tested OpenSSH server configurations for secure remote administration.
